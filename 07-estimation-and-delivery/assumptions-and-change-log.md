# Assumptions & Change Log — Group KPI Governance & Consolidation Capability

**Status: Draft.**

## Assumptions underlying the estimation model and phasing

| # | Assumption | If wrong, what changes |
|---|---|---|
| E1 | Executive approval of Finance's ownership role (US-03) is obtained within a reasonable consultation cycle | Phase 0's sizing (3–5 weeks) grows if this stalls — this is explicitly the main driver of Phase 0's range |
| E2 | The build-vs-buy decision ([`../06-rfp-and-commercial/rfp-document.md`](../06-rfp-and-commercial/rfp-document.md) §0) is made before Phase 1 starts, not during it | Phase 1's estimate (6–14 weeks) is a wide range precisely because this decision isn't made yet — narrowing it requires the decision first |
| E3 | Occupancy remains the only KPI with a confirmed definitional issue until Phase 3 validates otherwise | If revenue/ADR/RevPAR turn out to be affected sooner, Phase 3 work pulls earlier — this would not invalidate Phases 0–2, only resequence Phase 3 |
| E4 | Property D and the regulatory inventory remain genuinely separable from the rest of the rollout | If either turns out to be more deeply entangled with the core process than currently understood, Phases 4–5's "unsized" status may need to extend into a formal re-scope of earlier phases too |
| E5 | No new budget constraint or organizational change (e.g., group expansion — BRD §7 A4) emerges during delivery | A material change here would trigger a full re-estimate, not an incremental adjustment |

## Explicit non-assumptions

To avoid the opposite failure mode (assuming too little and leaving gaps that read as oversights), this section states what was deliberately **not** assumed, consistent with the rest of this project's practice:

- No specific currency figure, because none was ever disclosed (BRD §7, A2).
- No go-live date, because none was ever disclosed (BRD §7, A3).
- No headcount or team composition for delivery — IT resourcing was never discussed in a dedicated technology session with Omar.
